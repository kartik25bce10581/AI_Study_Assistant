# AI_Study_Assistant

## Overview

AI Study Assistant is a modular desktop application built using Python and Tkinter. It helps students manage tasks and receive AI-based study guidance.

---

## Project Structure

AI-Study-Assistant/
│── app.py (Main entry point)
│── chatbot.py (AI logic)
│── task_manager.py (File handling)
│── ui.py (GUI)
│── data/tasks.txt

---

## Features

* Task management (Add/Delete/Clear)
* Data persistence
* AI chatbot
* Study analytics
* Dark mode UI

---

## Tech Stack

Python, Tkinter, File Handling

---

## Run

python app.py

---

## Architecture

* app.py → starts application
* ui.py → handles GUI
* chatbot.py → AI logic
* task_manager.py → storage
